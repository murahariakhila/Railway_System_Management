                                   Railway Management System
The Railway Management System is a web-based application developed to automate and simplify railway operations such as train scheduling, ticket booking, passenger management, and seat reservation. The project was built using PHP and MySQL, with XAMPP used as the local server environment and phpMyAdmin for database management.
This system helps reduce manual work by digitally managing railway-related data and providing an organized workflow for both users and administrators. Passengers can search for trains, check seat availability, and book tickets, while administrators can manage train details, schedules, and passenger records efficiently.

       Features
Passenger registration and login system
Train search and schedule management
Ticket booking and cancellation
Seat availability checking
Passenger record management
Admin dashboard for managing railway operations
Real-time database connectivity using MySQL


           Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server Environment: XAMPP
Database Tool: phpMyAdmin


     How the Project Works
The application runs on a local server using XAMPP. Apache and MySQL services are used to host the project and manage the database. phpMyAdmin was used to create tables, store records, and perform database operations. PHP connects the frontend with the MySQL database to handle dynamic data such as bookings, schedules, and user information.


    Setup Instructions
Install XAMPP and start Apache and MySQL.
Place the project folder inside the htdocs directory.
Open phpMyAdmin and create the required database.
Import the SQL file into phpMyAdmin.
Run the project in the browser using:
http://localhost/project-folder-name
